{%- comment -%} Redirects legacy deep links from when this documentation lived on one URL. This is the one breakage a URL split cannot fix on the server: a fragment is never sent in the HTTP request, so `docs.infynipay.com/#webhooks` arrives looking exactly like `docs.infynipay.com/`. No redirect rule, rewrite or 301 can see it. The repair has to happen in the browser. Those links exist in plugin READMEs, in support email, in issue threads and anywhere else someone pasted one — none of which can be audited or updated. Without this they land on the home page and silently show the wrong content. Only fires when the hash matches no element on the current page, so a genuine same-page anchor (#rotation on the signing page, say) still works normally. Uses location.replace so the dead URL does not end up in the back history. Rendered on the home page only: that is where every legacy link lands. {%- endcomment -%}
