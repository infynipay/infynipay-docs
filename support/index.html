Before you write in

  • Check the payment in the Console — its state, fraud status and lastError usually explain the problem.
  • For webhook trouble, open the delivery log: it records every attempt with the status code your endpoint returned.
  • Reproduce in sandbox where you can. It is the same code path, without the money.
